# Постоянное хранение чатов и аватаров

Данные остаются **на компьютере пользователя** в каталоге проекта. Новых облачных сервисов и внешних библиотек для запуска не требуется.

| Папка или файл | Содержимое |
| --- | --- |
| `data/chats/index.json` | История разговоров, идентификаторы, выбор текущего диалога и ревизия |
| `data/avatars/index.json` | Список образов |
| `data/avatars/<id>.<ext>` | Оригиналы PNG/JPG/WebP/GIF без пережатия |
| `data/ui-preferences.json` | Настройки аватара, эффектов и выбранный образ |
| `data/assistant.json` | Существующий ключ Cloud.ru: **не включён** в экспорт переписки |

## Перенос старых данных

При первом доступном запуске общий чат переносит данные из `localStorage` в `data/chats/index.json`. Копия в браузере не удаляется. Библиотека образов копирует оригиналы из `IndexedDB` в `data/avatars`; после подтверждённой записи также оставляет их в браузере. Повторные переносы используют устойчивые идентификаторы, чтобы не создавать дубликатов.

**Важно о портах:** хранилища браузера привязаны к точному адресу, включая порт. Если старые данные были созданы на другом порту, новая страница не может прочесть их самостоятельно. Сначала откройте исходный адрес, пока он доступен, либо заранее экспортируйте переписку и импортируйте её в новом чате. Не очищайте историю браузера до проверки переноса.

Если сервер недоступен, чат использует прежнюю копию в браузере и сообщает об ошибке сохранения. Сервер отказывается перезаписывать повреждённый JSON-файл и отклоняет конфликтующие ревизии. Конфликт не разрешается бесшумным затиранием другого диалога.

## Резервная копия и восстановление

В существующих настройках чата доступны «Сохранить историю» и «Восстановить историю» — экспорт и импорт JSON диалогов. Перед импортом отображается подтверждение замены истории. Эти действия **не включают** изображения аватаров, документы или секреты Cloud.ru.

Для **полной локальной копии** остановите Miyuneya и скопируйте каталог `data` в надёжное место; восстановление выполняйте при закрытом приложении. При переносе на новый компьютер содержимое `data/avatars` и `data/ui-preferences.json` обеспечивает восстановление образов. Имейте в виду, что полный каталог `data` содержит API-ключ и личные документы **в незашифрованном виде**. Храните такую копию в защищённом месте и не добавляйте в Git.

## Ограничения

Библиотека образов рассчитана на 20 оригиналов до 15 МБ каждый. JSON-история проверяется на целостность и контролирует размер одной записи API, чтобы повреждённые данные или чрезмерный запрос не вывели локальный сервер из строя. Автоматического объединения изменений из одновременно открытых вкладок пока нет: при конфликте сервер сообщает о необходимости обновить историю.

Проверки TypeScript используют отдельный набор пакетов `tools/typecheck`. Это инструмент разработки и CI; для обычного `Miyuneya.bat` установка пакетов не требуется.
