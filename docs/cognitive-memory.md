# Когнитивная память Hayumeri

## Для чего

**Когнитивная память** — слой контекстного сопоставления над существующей памятью Miyuneya. Он помогает вспомнить не только отдельный факт, но и связанные события, темы и факты с указанием источника связи.

**Не является обучением весов языковой модели** и **не создаёт факты из гипотез**. Работает локально, без новых моделей или дополнительных платных API.

## Где находится

- Главная → значок **«Мозги Hayumeri»** (вверху справа) → **«Когнитивная память»** → кнопка **«Открыть когнитивную память»**.
- Рабочее пространство → значок **«Память»** → группа **«Знания»** → вкладка **«Когнитивная»**.
- Прямая ссылка: `/workspace#cognitive`.

## Принцип

1. Берутся факты из действующего `data/memory.json`. Неактуальные (`until`) и заменённые (`superseded`) записи исключаются из связей.
2. Сопоставляются **прямые связи** графа, **общие эпизоды**, **общие объекты** и **темы**, сформированные существующим механизмом консолидации.
3. Каждая ассоциация содержит **ID двух фактов, вид связи, ID и название источника**. Данные берутся только из уже сохранённой памяти.
4. Если любой связанный факт отмечен как **предположение** или **оспаривается**, связь получает статус «Требует подтверждения». Такие пары **не добавляются как достоверный контекст ответа**.
5. Когнитивный контекст подставляется в ответ только при совпадении темы с вопросом. Не более трёх связей, общий бюджет примерно 900 символов, без генерации новых утверждений.
6. При исправлении, удалении, забывании, истечении срока или выключении памяти производное представление немедленно пересчитывается; отдельный файл очищать не требуется.

## Контроль ошибок и ограничения

- Совместное упоминание двух фактов **не доказывает причинно-следственную связь**.
- Связи из тем или графа могут быть предложены моделью, поэтому отмечаются как контекст, а не как независимое подтверждение.
- Не делается предположений о вероятности истинности из числа повторений. Число связей — показатель структуры, не показатель интеллекта.
- Подсветка «Нужно перепроверить» выводит статус `inferred` или `contested`; ответы на открытые вопросы по-прежнему обрабатывает действующий механизм подтверждения.
- Производный обзор ограничен 96 связями, 30 неопределённостями и 12 вопросами. Он не использует дополнительные токены Cloud.ru. Поиск когнитивных связей работает по словам, даже если векторный поиск не настроен.
- В приватном режиме новые разговоры не записываются существующим механизмом; доступные пользователю старые записи по-прежнему отображаются, пока память не очищена.

## Данные и надёжность

Основное хранилище: **`data/memory.json`**, формат версии 1 не меняется. Когнитивное представление вычисляется на чтении и не сохраняется отдельно. Экспорт существующей памяти остаётся совместимым.

Тесты: парные связи, эпизоды, темы, происхождение, разделение проверенных и непроверенных записей, истечение срока, забывание, отключение памяти, совместимость с нормализацией старых файлов, показ в интерфейсе и использование при следующем ответе.

Внешний Cloud.ru не используется для создания когнитивных ассоциаций, но может потребоваться для других уже существующих функций памяти Miyuneya.
