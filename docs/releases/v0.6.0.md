# Miyuneya 0.6.0 — безопасные обновления

## Главное

- Проверка официальных стабильных выпусков репозитория **Aspksa/Miyuneya** непосредственно из настроек проекта.
- Отображение установленной и доступной версии, русское описание изменений, сообщения о недоступном релизе и ошибках подключения.
- Ручная проверка и загрузка обновления, а также необязательная ежедневная проверка и автоматическое скачивание **без автоматической установки**.
- Контроль состава пакета, безопасных путей файлов, размеров и SHA-256 каждого файла.
- Сохранение исходной версии, подготовка подмены и установка только через работающий запуск **Miyuneya.bat**.
- Перезапуск сервера после подтверждения владельца с сохранением локального адреса.
- Проверка целостности исходников и сборки, запуска веб-сервера и SQLite, автоматическое восстановление предыдущего кода при сбое.
- Защита пользовательских данных: файлы `data`, переписка, документы, ключ Cloud.ru и личные настройки не заменяются.
- Журнал результатов обновления без сохранения содержимого личных файлов и токенов.

Система не требует дополнительных пакетов npm и прав администратора. Обновления публикуются в официальных GitHub Releases после проверки тестов по версии-тегу.
