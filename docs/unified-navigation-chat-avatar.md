# Miyuneya — навигация, чат и адаптивный аватар

Дата внедрения: 31 октября 2026. Пакет: №1, 3, 4, 6, 10, 15, 17, 20, 21, 22, 24, 27, 28, 35, 36, 38.

## Навигация

- На главной появились прямые переходы в рабочее пространство: заметки и задачи, диск документов.
- В рабочем пространстве есть переходы на главную и «Мозги Hayumeri».
- Боковое меню рабочего пространства можно свернуть до узкой панели значков, а затем развернуть. Положение сохраняется отдельно для компьютера и мобильной ширины (на телефоне основное меню открывается как выдвижная панель).
- Функции памяти и настройки проекта остались на прежних местах; интерфейс мозгов не изменялся.
- Общие цвета, акценты, отступы и состояния фокуса заданы в `web/unified-ui.css`. У существующих пользовательских настроек темы и акцентного цвета остаётся приоритет там, где они применимы.

## Чат и файлы

Нажмите **«📎 Прикрепить»** под полем сообщения. Можно выбрать до четырёх файлов размером не более 15 МБ каждый.

**Порядок:** перед вызовом Cloud.ru сообщение сохраняется в SQLite. Затем каждый файл загружается в существующее хранилище вложений **данного разговора и сообщения**. Только после успешного сохранения вложений отправляется запрос модели.

По умолчанию в Cloud.ru попадают только имена файлов. Для поддержки **TXT, MD, CSV, JSON, LOG, TS, JS, PY, RS, SQL, HTML, CSS, XML, YAML** можно явно включить галочку передачи фрагмента: текстовые файлы до 1 МБ, по 5000 символов на файл и в пределах общего лимита сообщения. Это даёт возможность анализировать фрагменты без отдельной системы распознавания документов.

**PDF, изображения и другие двоичные форматы сохраняются как вложения, но не интерпретируются как прочитанные моделью.** Обработка PDF/изображений потребует отдельного проверенного извлекателя; не делайте вывод о содержимом файла только по его названию.

Если сеть прервала поток ответа, локальная история и уже полученная часть текста сохраняются прежним механизмом. Для сообщения с неполным ответом появляется **«Продолжить ответ»**. Кнопка запускает новый запрос с контекстом предыдущей части **только по нажатию**; автоматических расходных повторов нет. Сервер Cloud.ru не предоставляет здесь гарантии восстановления прежнего сокета/потока с того же токена.

Размер текста, плотность сообщений и ширина колонки доступны в существующих настройках чата. Положение и состояние чата (открыто, закрыто, свёрнуто) запоминаются локально отдельно для телефона и ПК.

## Аватар

- Плавное появление после загрузки сайта; пользовательские координаты не сбрасываются.
- Состояния показывают реальные события: готова к диалогу, ввод текста, генерация, ошибка сети, офлайн. Обозначение «ввод текста» **не означает работающий микрофон**.
- Три режима анимации: «Автоматически», «Экономно», «Выключено». При скрытой вкладке, системном ограничении движения или включённом режиме экономии передачи данных анимация приостанавливается.
- Аватар проверяет несколько безопасных положений и старается не перекрывать верхнюю панель, кнопки создания и редактирования; при открытии критических модальных диалогов временно теряет возможность перехватывать клики.
- Положение для компьютера и мобильного экрана сохраняется независимо. На телефоне остаются короткое нажатие для чата и долгое для настроек.

## Архитектура

| Файл | Назначение |
|---|---|
| `web/avatar.js` | Координация чата, настроек и архива |
| `web/avatar-state.js` | Состояния, экономия анимации, восстановление видимости и коллизии |
| `web/chat-attachments.js` | Выбор, проверка, передача файлов и явное разрешение отправки текста модели |
| `web/chat-format.js` | Безопасное DOM-форматирование сообщений и кода |
| `web/avatar-studio.js` | Библиотека и настройки изображений, как прежде |
| `web/unified-ui.css` | Общие токены и навигация |
| `web/workspace-layout.css` | Поздние стили рабочего пространства |
| `web/avatar-layout.css` | Поздние стили позиционирования и модальных окон |
| `web/avatar-experience.css` | Анимация, состояния, удобство ввода и вложений |

Состав файлов перечислен в `scripts/build.mjs`, разрешён локальным сервером через `server/app.ts` и включён в белый список безопасного обновления `scripts/update.mjs`. Новые зависимости и Python для запуска не добавляются.

## Проверка перед объединением

`npm run build`, `npm test`, `npm run check`, `npm run typecheck`, проверка HiDPI Chromium **320–5120 px**, Windows Node.js 22.18 и Windows portable/offline. Проверки не имитируют реальные ответы Cloud.ru и не заменяют ручную проверку на физическом сенсорном экране.

Без изменений: `data/`, SQLite-схема, ключи моделей, существующие заметки, задачи и «Мозги Hayumeri».
