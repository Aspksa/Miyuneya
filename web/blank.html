Нужен API-ключ сервисного аккаунта с доступом к Foundation Models. Сохраните значение Key Secret, проверьте срок действия ключа и интервалы доступа. Инструкция Cloud.ru

Ключ не загружен. Сохраняется только на локальном сервере, не в браузере.

При выборе внешней модели данные запросов могут передаваться другим провайдерам за пределами Cloud.ru. Для чувствительных документов проверяйте размещение в официальном каталоге моделей.

Для диалога выбирайте LLM-модель. Список API содержит также Embedding, Rerank, OCR и другие типы. Типы моделей Cloud.ru

Проверка доступа к каталогу и тест генерации — разные действия. Тест генерации отправит короткий запрос к модели и может расходовать платные токены.

Ключ хранится в data/assistant.json в исходном виде (без шифрования). Не пересылайте и не публикуйте этот файл.

Изменения сохраняются автоматически.

МИЮНЭЯ

Настройки аватара и чата

Аватар
Чат

Чат перемещается за верхнюю панель; его размер можно изменять за нижний правый угол. История хранится в этом браузере. Для ответов используется ключ Cloud.ru из настроек проекта.

Перетащите аватар левой кнопкой мыши. Короткий левый щелчок открывает чат, правый — эти настройки. На сенсорном экране откройте настройки через значок в заголовке чата.
