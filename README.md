# Miyuneya

Личное пространство на TypeScript: заметки, задачи, поиск, светлая/тёмная/системная тема и резервные копии. Версия **0.1.0**.

## Запуск в Windows

1. Скачайте репозиторий: **Code → Download ZIP**. Распакуйте весь архив.
2. Нужен **Node.js 22.18 или новее**. Если он уже установлен, ничего скачивать не нужно. Portable-вариант без администратора: скачайте официальный Windows ZIP с [nodejs.org](https://nodejs.org/), распакуйте его содержимое в `.runtime\node` внутри проекта, чтобы получился `.runtime\node\node.exe`.
3. Дважды нажмите **Miyuneya.bat**. Браузер откроется автоматически.

Запуск работает из папок с пробелами и кириллицей, в том числе с внешнего диска. BAT использует свою папку, проверяет Node.js, запускает сервер на свободном порту и открывает сайт после готовности. Повторный запуск открывает уже работающий экземпляр этой копии проекта. Окно запуска нужно оставить открытым; закрытие окна или Ctrl+C останавливает сервер. В случае ошибки окно показывает причину.

**`npm install` не требуется**: готовые JS-файлы включены в репозиторий, сторонних runtime-зависимостей нет. Без Node.js BAT показывает инструкцию; он не устанавливает программы автоматически. После подготовки Node.js интернет для работы не нужен.

## Данные

Данные сохраняются на компьютере в `data/workspace.json`, рядом с проектом, а не в браузере. Смена порта не теряет заметки. Для переноса закройте приложение и скопируйте всю папку, включая `data`. Эта папка и `.runtime` исключены из Git.

В **Настройки → Ваши данные** можно экспортировать JSON-копию и восстановить её. Восстановление заменяет текущие данные после подтверждения. Удаление записей требует подтверждения. Запись на диск атомарная; устаревшая вкладка получает конфликт версии вместо перезаписи свежих данных. При конфликте скачайте копию своих изменений и обновите вкладку. Приложение не исправляет повреждённый файл данных автоматически и не перезаписывает его.

Сервер слушает только `127.0.0.1`, не публикует личные данные в интернете и отдаёт только разрешённые файлы сайта. Общий размер данных — до 2 МБ, до 5 000 заметок и 5 000 задач. Это локальное приложение без авторизации: другие программы и пользователи с доступом к вашей папке могут прочитать данные.

## Разработка

```sh
npm start       # запуск и открытие браузера
npm run build   # сборка src/*.ts в dist/*.js встроенным средством Node.js
npm test        # тесты модели, HTTP, хранения и запуска
npm run check   # проверка соответствия готовых JS исходникам
```

Сборка удаляет аннотации TypeScript встроенным `stripTypeScriptTypes`; она не является проверкой типов `tsc`. Ядро и интерфейс написаны на TypeScript, запуск и сборка — на JavaScript, оформление — HTML/CSS. Python, Rust и SQL пока не подключены: текущим функциям они не требуются.

`src/` — интерфейс и модель данных; `server/` — локальный HTTP-сервер; `scripts/` — запуск и сборка; `dist/` — готовый сайт. Палитра и базовые принципы оформления взяты из предоставленного описания JUUNIBI: нейтральная светлая оболочка, золотой акцент, левое меню, мягкие панели. Иллюстрация лисицы выполнена в SVG.

ИИ-чат, облачные API, самостоятельное обучение и граф знаний в эту версию не входят. Счётчики на главной показывают реальные заметки и задачи.
